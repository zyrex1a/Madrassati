# Backend Madrassati

Le backend utilise Node.js, Express, MySQL, bcryptjs et JWT.

Pour l'installation complète, la configuration `.env`, le seed administrateur, les routes et les limites connues, consulter le [README principal](../README.md) et la [référence API](../docs/API_REFERENCE.md).

Rappel : configurer `.env` avant `npm run seed`. Aucun mot de passe administrateur par défaut ne doit être utilisé. Le compte initial est créé avec `ADMIN_EMAIL` et `ADMIN_PASSWORD` configurés localement.
